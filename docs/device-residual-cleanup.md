# 设备残留清理：沿用原同步目录

2026-09-25：取消助手的 v2/v3 空间迁移方案。当前实现直接维护原有
`sync/<device-id>/...` 文件和 `.qiwo-sync-manifest.json`，不创建新云端空间、
加入标记、永久停用记录或删除墓碑。此前的管理空间设计仅保留为历史实验代码；
助手不再注册对应命令，实际 native helper 拒绝旧迁移/加入/回收站任务。

## 用户约定

1. 在其他设备的助手中选择已弃用设备或其具体文件，查看实际文件及本机备份位置。
2. 暂停所有其他设备的手动和自动同步，保持暂停直到维护完成。确认范围后执行。
3. 助手备份每个选中文件的云端、本机版本以及清单，然后清理预览中的文件，并由深到浅移除范围内确认为空的目录。
4. 其他更新过的客户端再次拉取或同步时，识别云端已不存在的他机快照，先备份再删除
   本地缓存。它们从不上传他机快照，也不会把缓存条目重新写回云端清单。
5. 原设备恢复使用时保留本地词库，可继续使用相同 ID 重新发布自己的快照。无需解禁、
   迁移或重新加入；清理不会撤销其他词库已经学会的词条。

文件变化、清单变化、网络失败和部分完成都会停止任务并保留备份；重新扫描生成新的
预览，不重放已经开始的删除任务。预览 30 分钟后过期。执行只接受服务端保存的任务 ID，
不接受前端重新拼出的路径或内容。当前设备快照、公共配置、内部路径及符号链接不能清理。
预览列出候选空目录，支持单独清理已空的设备目录。保留 `sync/` 根目录、本机设备目录与备份。
删除目录前重新完整列举其内容；有文件、未知子项或新出现内容时保留目录，列表不完整或
不能确认目录类型时停止。不会为了移除父目录而删除未选中文件。本地只使用非递归 rmdir。

备份位于 Rime 用户目录 `.qiwo-sync/cleanup-backups/<任务ID>/`，包含 `plan.json`、
`remote/`、`local/`、原始清单和 `result.json`。自动移除的他机缓存另存到
`cleanup-backups/cache-<随机ID>/`。备份不参与同步，不自动删除。每个文件上限 64 MiB，
单次最多 512 个文件、256 个目录，两端文件合计 256 MiB。

## 并发边界

这是一项由用户暂停其他写入方后执行的维护操作，不是多端并发删除协议。坚果云接口
已观察到相同 If-Match 并发写入均成功，因此不使用能力检测结果来宣称原子性。
删除前再次核对内容；服务器提供的 ETag 仅作为附加条件。仍无法阻止不遵守暂停约定的
其他客户端在最后检查后写入。WebDAV 的目录 DELETE 具有递归语义，无法原子地要求
“仅当为空才删除”，因此目录检查到删除结束之间必须继续暂停所有其他写入方；不宣称
条件头能消除这个间隙。清单只移除本次选中键，并保留其他键和未知字段。

清理中先移除清单引用，再逐个删除文件，避免部分失败留下可下载清单中的失效链接；
可能留下的未记录文件可在下一次扫描中继续处理。写入开始后任务不可重放，以免后来
使用同一路径的新文件被旧任务删除。既不依赖强 ETag，也不尝试修改服务器配置。

## 客户端覆盖

- 当前 fcitx5 试用版：助手预览/确认、原生串行清理、导出和导入前核对缓存。
- 共享 Rust 核心：Push/Sync 仅上传自己的快照，Pull/Sync 备份并移除缺失的他机缓存。
- 助手自带 Rust 核心：保持同样的规则。
- Android 独立 Kotlin 实现：补齐相同归属、缓存清理和 Rime 导入/导出前检查；增加对应测试。
- 已安装旧版本或尚未更新子模块的其他端不会自动获得新行为，需随客户端升级发布。
  清理功能的原生任务接入当前仅覆盖 fcitx5，其余助手平台保持只读盘点。

云端清单缺失不被当成确定的删除信号；清单损坏或读取失败会中止检查。未被清单记录
但在云端仍然存在的文件也不会被自动当成垃圾删除。

## 验证

共享核心 `tests/cleanup.rs`：空设备目录、嵌套目录逐层移除、非空目录保留、目录越界、
目录列表不可信与删除失败后的重新预览，以及双侧备份、受保护路径、符号链接、变化后的预览、
清单缺失、部分失败、禁止重放、他机缓存不回传、原设备同 ID 恢复。
助手 `tests/cleanup-ui.cjs`：暂停和范围两项确认、仅提交任务 ID、失效预览和错误处理。
原生 `qiwo-fcitx5/addon/tests/desktop_cleanup.py`：使用独立 trial-autotest、私有 D-Bus、
真实 fcitx/Rime 和本机 WebDAV，不访问真实账号。

Android 使用临时便携 OpenJDK 21 和 Kotlin 2.1.20 编译实际同步、网络、缓存及 QiwoSync
编排源码，JUnit 同步引擎 9 项测试全部通过。日志、Base64 和 Android 平台编排接口使用
测试替身；实际网络测试使用本机 HTTP 服务。这不是 Android 平台集成测试。
现有 local.properties 指向 Windows SDK，当前环境没有 Android SDK，因此未构建 APK、
未在手机上安装或验证。
